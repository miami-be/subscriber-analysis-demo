# LIVEDUNE Instagram Analytics Prototype

## Описание проекта

Это прототип с веб-интерфейсом на Python, который анализирует чарт динамики подписчиков Instagram-аккаунта (на примере данных из Livedune) и предоставляет аналитику, сопоставимую по качеству с работой SMM-стратегиста. На основе анализа данных пользователь получает от 1 до 3 значимых инсайтов с предложениями конкретных действий, релевантных для категории его аккаунта.

## Основной функционал
- Загрузка и обработка mock-данных Instagram-аккаунта (подписчики, посты, комментарии, статистика).
- Отображение динамики роста подписчиков, анализ вовлечённости и аномалий.
- Генерация аналитических инсайтов, учитывающих специфику аккаунта.
- Веб-интерфейс для визуализации аналитики и рекомендаций.

## Подход к генерации инсайтов

1. **Сбор и структурирование данных**
   - Используются mock-данные, имитирующие выгрузку из Livedune: информация о подписчиках по дням, постах, комментариях, базовой статистике.
   - Данные агрегируются в pandas DataFrame для удобства анализа.

2. **Ключевые метрики и методы анализа**
   - **Динамика подписчиков**: рассчитывается ежедневный прирост, определяются периоды наибольшего и наименьшего роста.
   - **Лучший день для публикаций**: анализируется средний прирост подписчиков по дням недели, выявляется оптимальный день для постинга.
   - **Вовлечённость по типу постов**: анализируется engagement rate для разных типов контента (посты, сторис, рилсы и т.д.), выделяются наиболее эффективные форматы.
   - **Аномалии и их причины**: выявляются дни с резким ростом или падением подписчиков, анализируются связанные публикации и комментарии (в том числе — их тональность).

3. **Генерация инсайтов**
   - Для каждого аккаунта (с учётом его категории) формируется до 3 приоритетных инсайтов:
     - **Лучший день для постинга** — рекомендация публиковать контент в дни, когда наблюдается максимальный прирост подписчиков.
     - **Ростовые тренды** — анализируются периоды максимального роста, предлагается повторять успешные форматы/темы.
     - **Вовлечённость** — рекомендации по типу контента, который вызывает наибольший отклик аудитории.
     - **Аномалии** — если обнаружены всплески/падения, даётся объяснение (например, негативные комментарии или вирусный пост).
   - Каждый инсайт содержит краткое описание, конкретное действие и приоритет (CRITICAL, IMPORTANT, NORMAL).

4. **Визуализация и интерфейс**
   - Все инсайты, графики и метрики отображаются на веб-странице.
   - Пользователь видит понятные рекомендации и может быстро понять, как улучшить стратегию продвижения.

## Используемые данные
- **account.json** — базовая информация об аккаунте (имя, категория, стартовые значения).
- **statistics.json** — динамика подписчиков по дням.
- **posts.json** — информация о публикациях (дата, тип, вовлечённость).
- **comments.json** — комментарии, включая тональность (sentiment analysis).

## Технологии
- Python 3.9
- FastAPI (бэкенд)
- Jinja2 (шаблоны)
- Pandas (анализ данных)
- HTML/CSS (интерфейс)

## Как работает прототип
1. При запуске сервер обрабатывает mock-данные, строит необходимые метрики и генерирует инсайты.
2. На главной странице отображается краткая сводка, графики и рекомендации.
3. Все рекомендации формируются автоматически на основе анализа данных, без ручного вмешательства.
